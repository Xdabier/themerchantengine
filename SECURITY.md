# Security policy

## Supported versions

Security fixes land on the latest release only. Upgrade to the newest release before you report, if you can.

## Reporting a vulnerability

Please do not open a public issue, pull request or discussion for a security problem.

- Preferred: open a private report through GitHub at https://github.com/Xdabier/themerchantengine/security/advisories/new.
- Fallback: email badii@badii.studio with the subject line `SECURITY: <short summary>`.

Include what you can of the following:

- The affected component (API, admin, storefront, setup stepper or deploy templates) and the release or commit.
- The steps to reproduce, or a proof of concept against your own installation.
- The impact you observed or expect.

Test only against an installation you own. Do not access, change or delete data that is not yours, and do not run denial-of-service or social-engineering tests.

## What happens next

- We confirm receipt within five working days.
- We investigate, agree on a severity with you, and keep you updated while we work on a fix.
- We publish a fixed release and a GitHub security advisory. We credit you in the advisory unless you ask us not to.

Please give us a reasonable time to ship a fix before you disclose the problem publicly. We aim for 90 days or less.
