# Storefront API reference

This file used to be a hand-written catalogue of every customer-facing endpoint. It was last revised by hand on 2026-05-23 and had drifted from the controllers, so it was retired.

The reference is now generated from the code by `npm run docs:generate` and lives under `docs/site/reference/`:

- `docs/site/reference/storefront-api/<module>.md`, one page per module, with every route, its parameters, request body, responses and schemas.
- `docs/site/reference/store-config.md`, the schema of `GET /v1/store/config`.
- `docs/site/reference/error-codes.md`, every error code the API answers with.
- `docs/site/reference/_generated/openapi.storefront.json`, the OpenAPI document those pages render from.

The pages are published on themerchantengine.com in the reference track of the docs (under `/docs/reference/` for the latest release, and under the version segment for a pinned copy). CI regenerates the tree on every push and fails on a difference, so a page there is as current as the controllers. Comments in the code still cite this file by section name or by line number; every such citation refers to the module page of the same name under `docs/site/reference/storefront-api/`, and the line numbers refer to the retired file, not to this pointer. The Postman collection and environment that used to sit beside this file are generated by the same command now: `docs/site/reference/_generated/postman-collection.json` (both audiences, cookie-jar authentication), `docs/site/reference/_generated/postman-environment.json` (the local base URL and the locale) and `docs/site/reference/_generated/storefront-api.http` (every storefront operation as a REST Client request).
